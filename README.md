# 🎵 Music Store App

The **Music Store App** is a modern, responsive web application that allows users to search for songs by any singer and instantly view results fetched live from the **iTunes Search API**. Each song appears as a dynamic card featuring album artwork, song title, artist name, and an integrated audio preview player. Built with HTML, CSS, and JavaScript, this app provides a smooth and enjoyable music discovery experience.

---

## ✨ Features

- 🔍 **Search Songs by Singer Name** – Instantly fetch matching songs by typing the artist’s name.
- 🎧 **Audio Preview Player** – Listen to 30-second song previews directly in the app.
- 🖼️ **Dynamic Song Cards** – Cards display album art, song title, and artist name.
- ⚡ **Real-Time API Data** – Uses the iTunes Search API for accurate, up-to-date music results.
- 📱 **Responsive Design** – Works smoothly on desktops, tablets, and mobile devices.
- 🎨 **Modern UI** – Clean layout with hover effects, readable fonts, and card-based design.
